# AI Life OS 文档索引

## 文档状态定义

- **Draft**：草案，允许大范围修改
- **In Review**：正在评审
- **Approved**：已批准并形成 Baseline
- **Approved with Conditions**：有条件批准；条件、责任人和关闭标准必须明确
- **Superseded**：已被新版本替代
- **Superseded in part**：仅部分内容被后续决定取代，其余内容仍有效
- **Archived**：不再使用，仅保留历史
