# Max CEO 决策协议 v0.1

- **状态**：已生效（Max 确认，2026-10-08）
- **目标**：Max 以 CEO 方式投入——每天 ≤5 分钟、每周 ≤15 分钟；其余由代理团队承担。

## 1. 决策分级

| 级别 | 内容 | 处理 |
|---|---|---|
| Max 保留 | 方向选择（原型/功能取舍）、不可逆或高风险（隐私模型、数据结构定稿、对外发布、真实数据、危机场景）、里程碑验收（G0–G6 gate） | 一页决策包，Max 回复选项 |
| 代理默认 | 执行细节、文档格式、版本推进、检查与修复、任务拆分 | 默认通过 + 记录 `docs/09-decisions/`，Max 事后可推翻 |
| 升级条件 | 范围变更、保留决策被触碰、待决策队列 >3 项 | 才允许打断 Max；执行问题永不升级 |

## 2. 决策包格式（强制）

任何需要 Max 决定的事项，必须压缩为一页：

1. **要决定什么**（一句话）
2. **推荐选项 + 理由**（≤5 行）
3. **与上版/现状差异**（一张小表或要点）
4. **不可逆风险**（明确"低/中/高"）
5. **备选方案**（含"退回修改"）

附：批准后自动动作清单（Max 不需要二次确认）。不合格的决策包由 lifeospm 打回重做，不得以上抛全文代替。

## 3. 节奏

- **每天 ≤5 分钟**：看"待决策队列"（每项一行），逐项回复选项编号。
- **每周 ≤15 分钟**：自动周报（进度、决策记录、下周里程碑）+ 路线校准；只讨论方向，不复盘细节。

## 4. 原型决策流（G2 起适用）

AI 并行产出 **3 个差异化的可点击 HTML 原型**（每个附一句话定位 + 取舍表）→ Max 选一个并圈注 → 修改轮 **≤2 轮** → 冻结为设计基线 → 进开发。可选：定稿后经 html.to.design 导入 Figma 精修，AI 通过 Figma 连接器读回 design tokens 与设计稿生成代码。

## 5. 护栏

- 沿用 AGENTS.md：创建者不批准自己的工作；不可逆操作（发布、破坏性迁移、敏感数据用途、临床声明）必须 Max 明示批准。
- 授权默认通过不等于放行高风险；违规即收回对应代理的默认权限。
- 本协议修改需 Max 批准（走决策包）。
